# 📰 News Aggregation Portal

A modern News Aggregation Portal that automatically collects and displays the latest news from multiple trusted sources in one place. The application provides categorized news, secure user authentication, and a responsive user interface for an enhanced reading experience.

---

## 🚀 Features

- 📰 Latest news from multiple sources
- 🔍 Search news articles
- 📂 Category-wise news (Technology, Sports, Business, Entertainment, Health, etc.)
- 👤 User Registration & Login
- 🔒 Secure Authentication
- ❤️ Save favorite articles (Optional)
- 📱 Fully Responsive Design
- ⚡ Fast Loading Interface
- 🌙 Clean and Modern UI

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/kaliraj-123/News-aggregation-portal.git
```

Move into the project

```bash
cd News-aggregation-portal
```

---

## Backend Setup

Configure your MySQL database in:

```
application.properties
```

Example:

```properties
spring.datasource.url=jdbc:mysql://localhost:3306/news
spring.datasource.username=root
spring.datasource.password=your_password

spring.jpa.hibernate.ddl-auto=update
spring.jpa.show-sql=true
```

Run the Spring Boot application.

---

## Frontend Setup

```bash
npm install
npm start
```
